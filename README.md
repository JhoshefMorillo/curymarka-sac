# Curymarka SAC — Propuesta de Página Corporativa

Propuesta de sitio web corporativo desarrollada como proyecto de portafolio, inspirada en una empresa real peruana dedicada al mantenimiento electromecánico, aire comprimido y suministro de oxígeno medicinal para instituciones de salud.

> **Nota:** Este es un proyecto de portafolio y no constituye el sitio web oficial de la empresa. Fue desarrollado únicamente con fines de demostración de habilidades en desarrollo frontend.

## Descripción

Sitio institucional de una sola marca, construido 100% con HTML, CSS y JavaScript puro (sin frameworks), pensado para transmitir seriedad, experiencia técnica y confianza — valores clave para una empresa que trabaja con instituciones como EsSalud y MINSA.

## Páginas

- **Inicio** — presentación general, video de fondo, motivos para elegir la empresa y carrusel de instituciones con las que ha trabajado
- **Nosotros** — historia de la empresa, línea de tiempo, experiencia y compromiso
- **Servicios** — catálogo de servicios ofrecidos, proceso de trabajo y preguntas frecuentes
- **Contacto** — formulario de contacto funcional (EmailJS), mapa y botón directo de WhatsApp
- **Legal** — política de privacidad y términos y condiciones

## Funcionalidades técnicas

- Estructura modular con **partials** (header y footer reutilizables mediante `fetch`)
- **Formulario de contacto funcional** integrado con EmailJS (sin backend)
- **Menú móvil** con animación tipo hamburguesa
- **Carrusel infinito** de clientes/instituciones, con pausa al pasar el mouse
- **Animaciones al hacer scroll** (fade + desplazamiento) mediante `IntersectionObserver`
- **Botón flotante de WhatsApp**
- Diseño **100% responsive**

## Tecnologías

HTML5, CSS3, JavaScript (vanilla), EmailJS
